# Olie.co.nz — Powered by Apex

Outlined SVG artwork: scalable, transparent and independent of installed fonts.

- `olie-logo.svg`: dark wordmark for light surfaces.
- `olie-logo-inverse.svg`: white wordmark for dark surfaces.
- `olie-mark.svg`: compact O / house mark.
- `olie-tile.svg`: charcoal home-screen tile, 2048 × 2048 nominal size.

Wordmark outlines use Space Grotesk, the app’s existing open font. Charcoal #16181A, Apex red #E4002B. The display name does not change domain routing or sign-in configuration.
