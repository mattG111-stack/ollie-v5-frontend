# Olie.co.nz — Powered by Apex

The website logo combines the approved teal house artwork with an outlined wordmark.

- `olie-teal-house.png`: approved house artwork, shared with the app icon and `ApexMark`.
- `olie-logo.svg`: dark text-only wordmark for light surfaces.
- `olie-logo-inverse.svg`: white text-only wordmark for dark surfaces.
- `olie-mark.svg`: compact O / house mark.
- `olie-tile.svg`: charcoal home-screen tile, 2048 × 2048 nominal size.

`ApexLogo` composes the house and the appropriate wordmark for the sidebar, sign-in, sign-up and onboarding screens. Wordmark outlines use Space Grotesk, the app’s existing open font. The identity uses charcoal, teal and white.
